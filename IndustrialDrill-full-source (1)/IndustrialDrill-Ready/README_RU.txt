INDUSTRIAL DRILL — проект мода для Minecraft Java 26.3 / Fabric

Честно о статусе:
Это расширенный исходный прототип с ездовой Entity, серверным бурением, рецептом и локализацией. В этой среде не установлен Minecraft/Gradle и сборку запустить не удалось, поэтому я не могу гарантировать, что сигнатуры API полностью совпадают с 26.3. Готовый JAR не приложен. Код следует считать проектом для сборки и проверки, а не подтверждённым релизом.

Установка проекта для сборки:
1. Установи JDK 25.
2. Установи IntelliJ IDEA Community (бесплатно).
3. Распакуй архив и открой папку IndustrialDrill-Ready как Gradle project.
4. Подожди скачивания зависимостей.
5. В терминале в папке проекта выполни: gradle build
6. Если сборка успешна, JAR будет в build/libs/.
7. Скопируй JAR в .minecraft/mods. Нужны Fabric Loader и Fabric API для Minecraft 26.3.

В игре:
- Предмет «Комплект промышленного бура» планируется крафтить по рецепту из железа, алмаза, поршней, печи и редстоуна.
- Для появления самой машины в текущем прототипе пока нет полноценного пользовательского способа размещения предметом; entity registration и vehicle logic есть, но нужен следующий этап: item-use spawn, клиентский renderer/модель и тестирование движения.
- Бурение сделано на сервере, 3 блока шириной и 2 высотой за импульс; защищённые блоки вроде бедрока/порталов исключены. Включено правило mobGriefing и проверка mayInteract.

Если сборка выдаст ошибку:
Скопируй сюда первые строки ошибки из Gradle Build Output — можно исправить проект по фактической сигнатуре API, не нужно разбираться самому.
